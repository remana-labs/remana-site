# remana.ai Website Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put `remana.ai` live as a static Astro site on Cloudflare Pages with six pages, a privacy policy written from the app's real data flow, brand assets, and a waitlist whose emails land in our own D1 database.

**Architecture:** A new public repo `remana-labs/remana-site`. Astro builds to `dist/`; Cloudflare Pages deploys it from GitHub (preview per PR, production from `main`). One Pages Function (`functions/api/waitlist.ts`) verifies a Turnstile token and inserts into D1. No client JavaScript except the Turnstile widget. Design tokens are copied from the monorepo's `DESIGN.md` into a JSON file that generates the CSS, so the values have one source inside this repo.

**Tech Stack:** Astro 7 (static output), Node 22, Cloudflare Pages + Pages Functions + D1 + Turnstile + Web Analytics, `@fontsource/plus-jakarta-sans`, vitest, wrangler 4, GitHub Actions (GitHub-hosted).

**Spec:** `docs/superpowers/specs/2026-09-27-website-design.md` (in `remana-labs/remana`). This plan lives in the monorepo because the site repo does not exist until Task 1; copy both files into the site repo's `docs/` in Task 1 so they travel with the code.

## Global Constraints

- Repo `remana-labs/remana-site` is **public**. CI runs on `ubuntu-latest` only — **never** `runs-on: self-hosted` (the org's runners are this dev machine; `docs/engineering/repo-transfer-checklist.md`).
- Node `22.x` (Astro 7 requires ≥ 22.12; local is 22.22.1). Pin with `.node-version` = `22` so Cloudflare Pages builds with the same major.
- No third-party requests at runtime except Cloudflare's own (Turnstile, Web Analytics). No Google Fonts, no Google Analytics, no external form service.
- Colours, spacing, radii and type come from `DESIGN.md` (monorepo, frontmatter) via `src/styles/tokens.json` — never a hex literal in a component or page.
- Copy rules: lowercase `remana` in the lockup; the mark sits left of the name; the wordmark is `on-surface`, never the accent. Contact address is `hello@remana.ai` everywhere public; `admin@remana.ai` appears nowhere on the site.
- Privacy policy sentences must match the code: diarization holds audio **up to 1 hour**; speech-to-text and extraction keep nothing; memory, transcripts and voiceprints stay on the phone; Google sign-in via Firebase; Cloudflare for the site, gateway, Turnstile and analytics. Do not publish "no transcript is retained" until the vLLM `--disable-log-requests` fix is confirmed (spec → "Three facts").
- Secrets never enter the repo: `TURNSTILE_SECRET` is a Pages secret; `PUBLIC_TURNSTILE_SITE_KEY` is a plain var. Locally use Turnstile's documented test keys (site key `1x00000000000000000000AA`, secret `1x0000000000000000000000000000000AA`, always pass).
- Every page works at 360 px wide with a 16 px gutter, in both colour schemes, with no JavaScript (the waitlist form degrades to "email hello@remana.ai").
- Commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. Conventional prefixes.

## Review Focus

Inputs the spec implies but no obvious test covers; each gets a test in the task that owns it:

1. **Waitlist body arrives as `application/x-www-form-urlencoded` from the no-JS `<form>` and as JSON from the enhanced path** — both must parse (Task 4, `parseWaitlistBody` tests).
2. **Email `" Reza@Example.com "`** — must normalise to `reza@example.com`; a second submission of the same address must return `ok` and add **no** row (Task 4, `normaliseEmail` test + D1 `INSERT OR IGNORE` on a `UNIQUE` column, verified by the wrangler curl in Step 12).
3. **Turnstile siteverify unreachable** — must return `502` and insert nothing, not `500` with a half-written row (Task 4, `verifyTurnstile` test with a throwing `fetch`).
4. **`/.well-known/apple-app-site-association` has no file extension** — Pages would serve it as `application/octet-stream`; a `_headers` rule must force `application/json` (Task 2, `check-links` also asserts the header file names both paths).
5. **A privacy-policy edit without a new change-log entry** — the page must not silently change; the guard test compares the last change-log date to the file's last git commit date (Task 2, `check-policy-date` test, seen failing first).

describe("privacy policy change log", () => {
  it("has a dated entry no older than the file's last commit", () => {
    const md = readFileSync("src/pages/privacy.md", "utf8");
    const dates = [...md.matchAll(/^- \*\*(\d{4}-\d{2}-\d{2})\*\*/gm)].map((m) => m[1]);

    const latest = dates.sort().at(-1)!;

`src/lib/waitlist.ts`:

```ts
const EMAIL = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

export function normaliseEmail(raw: string): string | null {
  const e = raw.trim().toLowerCase();
  return e.length > 0 && e.length <= 254 && EMAIL.test(e) ? e : null;
}

export function parseWaitlistBody(contentType: string | null, text: string) {
  const none = { email: null as string | null, token: null as string | null, source: "" };
  const ct = (contentType ?? "").split(";")[0].trim();
  try {
    if (ct === "application/json") {
      const j = JSON.parse(text);
      return { email: str(j.email), token: str(j.token), source: str(j.source) ?? "" };
    }
    if (ct === "application/x-www-form-urlencoded") {
      const p = new URLSearchParams(text);
      return { email: p.get("email"), token: p.get("cf-turnstile-response"), source: p.get("source") ?? "" };
    }
  } catch { /* malformed body: fall through to none */ }
  return none;
}
const str = (v: unknown) => (typeof v === "string" ? v : null);

export async function verifyTurnstile(secret: string, token: string, ip: string | null, fetchFn: typeof fetch): Promise<"ok" | "rejected" | "unavailable"> {
  if (!token) return "rejected";
  const body = new URLSearchParams({ secret, response: token });
  if (ip) body.set("remoteip", ip);
  try {
    const r = await fetchFn("https://challenges.cloudflare.com/turnstile/v0/siteverify", { method: "POST", body });
    const j = (await r.json()) as { success?: boolean };
    return j.success ? "ok" : "rejected";
  } catch {
    return "unavailable";
  }
}
```

import { normaliseEmail, parseWaitlistBody, verifyTurnstile } from "../../src/lib/waitlist";

interface Env { DB: D1Database; TURNSTILE_SECRET: string }

const json = (status: number, body: unknown) =>
  new Response(JSON.stringify(body), { status, headers: { "Content-Type": "application/json", "Cache-Control": "no-store" } });

export const onRequestPost: PagesFunction<Env> = async ({ request, env }) => {
  const text = await request.text();
  if (text.length > 4096) return json(413, { ok: false, error: "too large" });
  const { email: raw, token, source } = parseWaitlistBody(request.headers.get("content-type"), text);
  const email = raw ? normaliseEmail(raw) : null;
  if (!email) return json(400, { ok: false, error: "email" });
  const verdict = await verifyTurnstile(env.TURNSTILE_SECRET, token ?? "", request.headers.get("cf-connecting-ip"), fetch);
  if (verdict === "unavailable") return json(502, { ok: false, error: "verification unavailable, try again" });
  if (verdict === "rejected") return json(400, { ok: false, error: "verification" });
  // INSERT OR IGNORE: a repeat signup is a success with no new row, never an error that leaks membership.
  await env.DB.prepare("INSERT OR IGNORE INTO waitlist (email, source) VALUES (?1, ?2)").bind(email, source.slice(0, 200)).run();
  const wantsHtml = (request.headers.get("accept") ?? "").includes("text/html");
  return wantsHtml ? Response.redirect(new URL("/joined", request.url).toString(), 303) : json(200, { ok: true });
};
